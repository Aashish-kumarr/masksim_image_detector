# DeepFakeDSP / MaskSim — Full Architecture & Retraining Guide

DeepFakeDSP is a full-stack web application and machine learning microservice for **frequency-domain AI-image forensic analysis**. It utilizes the **MaskSim (Masked Spectrum Similarity)** framework to identify synthetic images generated by diffusion models and GANs by analyzing residual high-frequency spectral artifacts.

---

## 1. System Architecture Overview

```text
React Frontend (Vite)
       │  HTTP / REST
       ▼
Node.js / Express Backend (Gateway & Auth)
       │  HTTP / Multipart
       ▼
Python FastAPI ML Service
       │  In-Memory PyTorch Model
       ▼
PyTorch DnCNN + MaskSim Inference Engine
```

1. **Frontend (React)**: Interacts solely with the Express backend API. Renders detection results, residual heatmaps, 2D FFT magnitude spectra, and 1D radial frequency distribution charts.
2. **Backend (Node.js/Express)**: Acts as an API gateway. Handles file upload validations (Multer), CORS, rate limiting, request tracing, and forwards requests to the ML Service via `FastApiMlAdapter` (or falls back to `MockMlAdapter`).
3. **ML Service (Python/FastAPI)**: Serves the PyTorch model checkpoint. Executes RGB to YCbCr conversion, DnCNN residual extraction, 2D FFT transformation, log-magnitude spectrum generation, and MaskSim cosine similarity scoring.
4. **Training Workspace (`masksim_project`)**: Isolated workspace containing raw datasets, preprocessing scripts, DnCNN pretrained weights, and the primary Jupyter Notebook used to train MaskSim model checkpoints.

### 2.1 `/masksim_project/` (Training & Research Workspace)
This folder contains everything needed to train, fine-tune, and evaluate MaskSim models:

* **`dsp_01.ipynb`**: Primary Jupyter Notebook used for model development and training.
  * **Dataset Loader**: Preprocesses image pairs (real pristine images vs. synthetic AI outputs).
  * **Pipeline Operations**: Converts images from RGB to YCbCr, extracts residual noise via DnCNN, computes 2D FFTs with `fftshift`, and calculates log-magnitude spectra.
  * **MaskSim Module**: Trains the learnable spatial frequency mask (`mask_raw`), reference spectrum (`ref`), and logistic calibration parameters (`a`, `b`).
  * **Evaluation**: Computes accuracy, Precision, Recall, F1-Score, and ROC-AUC across dataset splits.
* **`checkpoints/`**: Directory where trained PyTorch checkpoints are saved:
  * `masksim_sd14_best.pt`: Best-performing model state dictionary (used in production).
  * `masksim_sd14_deploy.pt`, `masksim_sd14_latest.pt`, `masksim_sd14_epoch1.pt`: Intermediate training checkpoints.
* **`pretrained/`**: Contains pre-trained weights for residual extraction:
  * `dncnn_color_blind.pth`: Pretrained DnCNN 20-layer color denoising model used for extracting noise residual maps from input images.
* **`data/`**: Datasets used for training and benchmarking:
  * `real/` & `raise_processed/`: Pristine real image samples (from the RAISE dataset).
  * `fake/` & `fake_sd14_raw/`: Synthetic images generated using Stable Diffusion v1.4.
  * `synthbuster/`: Benchmark evaluation dataset containing samples across 9 generators (*DALL-E 2, DALL-E 3, Midjourney v5, SD 1.3, SD 1.4, SD 2.0, SD XL, Firefly, GLIDE*).
* **`outputs/`**: Generated plots, confusion matrices, ROC curves, and saved spectral visualization figures.

### 2.2 `/ml-service/` (Production Inference Service)
FastAPI microservice that loads the PyTorch model checkpoint and runs real-time inference:

* **`app/`**: Core Python package for the service.
  * **`model.py`**: Pure PyTorch definitions of:
    * `rgb_to_ycbcr()`: Matrix transformation for YCbCr color space.
    * `DnCNN`: 20-layer residual convolutional network.
    * `log_mag_spectrum()`: `torch.fft.fft2(norm="ortho")` + `fftshift` + log magnitude calculation.
    * `MaskSim`: PyTorch module implementing cosine similarity against learned mask and reference parameters.
  * **`inference.py`**: Model loading and image processing pipeline:
    * `load_checkpoint()`: Loads `masksim_sd14_best.pt` into memory once during startup.
    * `predict_image()`: Performs EXIF orientation fixing, 512×512 center cropping, scaling to [0, 1], residual extraction, and inference under `torch.inference_mode()`.
  * **`explainability.py`**: Forensic artifact generators:
    * Generates Base64 PNG visualizations for residual maps, FFT magnitude maps (Combined, Y, Cb, Cr), and learned spatial masks.
    * `generate_frequency_profile()`: Computes 1D radial frequency profile data (binning 2D spectrum magnitudes by radial distance from center).
  * **`main.py`**: FastAPI endpoints (`/v1/health`, `/v1/model-info`, `/v1/predict`), exception handlers (`ValueError`, `RuntimeError`), and CORS/lifespan setup.
  * **`config.py`**: Dynamic configuration loader that converts relative model paths into absolute paths.
* **`models/`**: Production storage for active PyTorch model checkpoints (`masksim_sd14_best.pt`).
* **`inspect_checkpoint.py`**: Utility script to inspect PyTorch checkpoint keys and tensor shapes.
* **`requirements.txt`**: Production Python dependencies (`torch`, `torchvision`, `fastapi`, `uvicorn`, `pillow`, `numpy`, `python-multipart`).

## 3. How to Resume Training & Train New Models

If you want to train a new model checkpoint (e.g., fine-tuning on new generators like **Midjourney v6**, **SDXL**, or **DALL-E 3**), follow these steps:

### Step 1: Prepare the Dataset
1. Place real pristine images in `masksim_project/data/real/`.
2. Place synthetic generator outputs in `masksim_project/data/fake/` (or inside a subfolder in `masksim_project/data/synthbuster/`).

### Step 2: Open the Training Notebook
Launch Jupyter Lab/Notebook inside the `masksim_project` directory:
```powershell
cd masksim_project
jupyter notebook dsp_01.ipynb
```

### Step 3: Run the Training Pipeline
Inside `dsp_01.ipynb`:
1. Ensure `pretrained/dncnn_color_blind.pth` is present.
2. Run the dataset initialization cells to extract noise residuals for your new image set.
3. Train the `MaskSim` module. The loss function will optimize:
   - `mask_raw`: Spatial frequency weighting parameters.
   - `ref`: The template reference spectrum.
   - `a` & `b`: Scale and shift parameters for logistic probability calibration.
4. Save your new checkpoint to `masksim_project/checkpoints/`:
   ```python
   torch.save({
       'dncnn_state_dict': dncnn.state_dict(),
       'masksim_state_dict': masksim.state_dict(),
       'epoch': epoch,
       'best_acc': best_acc
   }, 'checkpoints/masksim_new_model.pt')
   ```

### Step 4: Deploy the New Checkpoint to Production
1. Copy the newly trained checkpoint file to `ml-service/models/`:
   ```powershell
   copy masksim_project/checkpoints/masksim_new_model.pt ml-service/models/
   ```
2. Update `ml-service/.env` to reference the new file:
   ```env
   MODEL_PATH=./models/masksim_new_model.pt
   MODEL_THRESHOLD=0.5
   MODEL_VERSION=masksim-v2
   ```
3. Restart the FastAPI service. The application will immediately begin using your new model!

## 4. How to Start the Services

Open 3 separate terminals from the project root:

### Terminal 1: ML Service (FastAPI)
```powershell
cd ml-service
.\.venv\Scripts\Activate.ps1
uvicorn app.main:app --reload --port 8000
```

### Terminal 2: Backend (Express)
```powershell
cd backend
npm run dev
```

### Terminal 3: Frontend (React)
```powershell
cd frontend
npm run dev
```

Open your browser at **`http://localhost:5173`**.
