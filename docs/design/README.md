# Design Handoff

This directory is the visual source of truth after Stitch exploration.

## Before Antigravity performs final UI implementation

Add:

```text
DESIGN.md
```

It should contain:

- selected Stitch concept
- colors/tokens
- typography
- spacing
- borders/radii
- button states
- form/dropzone states
- navigation
- analysis workspace layout
- result layout
- responsive rules
- accessibility rules
- links/references to approved Stitch screens

## Rule

Antigravity must not invent a replacement design system once `DESIGN.md` is approved.
